# Quiz


## Level 1:

1. Add more questions to the quiz (could be more questions of the same type, multiple choice questions or true/false questions).
2. Change the scoring of your quiz (harder questions could be worth more points and you could take away points for incorrect responses).
3. At the end of the questions, display a different message depending on the score (for example, if the score is greater than or equal to 5, then display a well done message, or if the score is 0, then display a different message).
4. Make the quiz non-case sensitive (so for the first question should accept incorrectly and Incorrectly).
	
## Level 2:

Write a quiz game from scratch! (for example, you could do a maths quiz, which randomly generates questions)
